# LaundryforU

## 📖 About
LaundryforU is a laundry management system developed as a university project. This application helps manage laundry orders and customer data efficiently.

## ✨ Features
- User Login
- Laundry Order Management
- Customer Management
- Transaction Management
- User-Friendly Interface

## 🛠️ Technologies Used
- Java
- Maven
- MySQL
